# BridgeRock 🌉

BridgeRock is a project idea presented through a website instead of a traditional PowerPoint submission for a hackathon.

The goal was to demonstrate the concept, features, and workflow of the idea in a more interactive and engaging format.

## 🌐 Live Demo

https://bridge-rock.vercel.app

## 💡 About the Project

Instead of submitting a presentation, this project showcases the hackathon idea through a simple website interface.
It explains the concept, highlights the problem being solved, and presents the proposed solution in an interactive way.

## 🚀 Features

* Interactive presentation of the project idea
* Clean and simple UI
* Web-based alternative to traditional PPT submissions
* Fast deployment using Vercel

## 🛠 Tech Stack

* HTML
* CSS
* JavaScript
* Claude AI (development assistance)
* Vercel (deployment)

## 🎯 Purpose

This project was created as part of a **hackathon idea submission process**, where participants were encouraged to present their concepts through a **website instead of slides**.
